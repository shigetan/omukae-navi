# おむかえナビ｜保護猫・保護犬を迎えるおうちのAI安全チェック

保護猫・保護犬をお迎えする前の**おうちの安全 AI事前チェック＆提出用レポート作成Webアプリ**（`omukae-navi`）です。  
Google Japan 25周年記念 **「Google AI Challenge 2026」** 応募作品として、Google Antigravity・Google AI Studio・Google Gemini を活用して開発しました。

- **Web体験版デモ（ブラウザでそのまま操作できます）**: https://shigetan.github.io/omukae-navi/

## 解決したい課題
自治体（動物愛護管理センターなど）や保護団体から保護猫・保護犬を受け入れる際、職員・スタッフによる事前の自宅訪問チェックが行われます。  
しかし、立ち会いの日程調整（平日・休日を問わず）や自宅を見られる心理的ハードル、職員・スタッフの移動や訪問コストが双方の大きな負担になっています。

**おむかえナビ**は、Google のマルチモーダルAI（Gemini）を活用して以下を支援します。
1. **お迎え元に合わせた基本設定**：保護猫・保護犬の選択に加え、「自治体・動物愛護管理センター」「民間の保護団体・保護カフェ」「個人の保護主さん・これから検討中」および「先住ペットあり」に合わせてAIのチェック観点を自動調整。
2. **お部屋の写真AIチェック＆100均お買い物リスト**：窓・玄関・リビング・飼育スペースの写真から脱走リスクや有毒植物・電気コード等を診断。テスト採点っぽくない **「おうち安心メーター」**、身近な **「100均・ホームセンター対策お買い物リスト」**、対策後の撮り直し **「ビフォー／アフター記録」** に対応。
3. **AIやさしいヒアリング**：住居条件や留守番時間、家族の同意、動物病院の備えなど5項目を、タップ候補付きチャットでテンポよく確認。
4. **ご本人向けガイド＆A4提出用レポート**：画面上は応募者向けの優しいガイドを初期表示し、提出用プレビューおよびA4印刷（PDF保存）では職員様向け確認サマリー・お買い物進捗・担当者確認欄を出力。

> ※ **責任あるAIの立ち位置**：AIが最終的な合否を決めるのではなく、受け入れ希望者の事前準備を優しく支え、保護団体・自治体職員の最終判断と確認作業を助けるツールとして設計しています。

## 起動方法（本番 Gemini API で動かす場合）

追加ライブラリのインストールは不要（Python 3 標準ライブラリのみ）で動作します。

1. `.env.example` をコピーして `.env` ファイルを作成し、`GEMINI_API_KEY` に Google AI Studio のAPIキーを設定します。
   ```bash
   cp .env.example .env
   ```
2. サーバーを起動します。
   ```bash
   python3 server.py
   ```
3. ブラウザで `http://localhost:8080` を開きます。同じWi-Fiにつないだスマホからもアクセスしてカメラ撮影でテストできます。

※ GitHub Pages 上の公開URLでは、APIキー不要ですぐ操作感を試せる **Web体験版モード** として全4ステップ（サンプル写真チェック・ビフォー／アフター再チェック・5問ヒアリング・お買い物チェック・A4提出レポート印刷）を体験できます。
